# blog.alunduil.com

Personal blog. Built with [Astro] and the [AstroPaper] theme. Deployed to
GitHub Pages on push to `main`.

## Local development

```sh
pnpm install
pnpm dev      # http://localhost:4321
pnpm build    # produces ./dist
```
