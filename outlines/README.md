# Outlines

Planning outlines for blog posts — one per post, filename matching the
post slug (e.g. `the-tool-was-never-the-lever.md` for the post of the
same name).

These are scaffolding, not content. They sit outside `src/`, so Astro
never publishes them, and they're excluded from the prose linters and
lychee. They're kept in version control as a record of each post's
intended structure. See the `draft-post` skill for how they're produced
(a Duarte-based pass: content contrast for the arc, emotional contrast
for the braid).
